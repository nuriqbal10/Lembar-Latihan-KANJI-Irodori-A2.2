Tersedia dalam format **Web Application (SPA GitHub Pages)**, **Print-Ready HTML (A4)**, dan **Native Microsoft Word (`.docx`)**.

---

## 🌟 Fitur Utama Aplikasi

### 1. 📐 Standar 10-Grid Tian-zi-ge (十字リーダー格)
Setiap huruf Kanji disajikan dalam 10 kotak latihan sistematis:
- **Kotak ① (Guidance):** Diagram vektor resolusi tinggi dengan **nomor urutan goresan (*numbered stroke order*)** dan garis silang bantu.
- **Kotak ② (Contoh Model):** Huruf acuan tebal berstandar font resmi buku teks Jepang (*UD Digi Kyokasho / UD デジタル 教科書体*).
- **Kotak ③ & ④ (Tracing / Jiplak):** Huruf berbayang halus (*calm pastel gray*) untuk melatih memori otot motorik tangan.
- **Kotak ⑤ s.d. ⑩ (Mandiri):** 6 kotak kosong bertanda silang putus-putus untuk latihan menulis berulang kali.

### 2. 🎨 Desain Pastel Claymorphism yang Menenangkan
- Tampilan antarmuka lembut bertema *Claymorphism* dengan sudut membulat *pillowy*, bayangan ganda halus, dan warna pastel kalem (*Rose, Sky Blue, Sage Green, Warm Sand, Lavender*).
- Didesain secara ergonomis agar tidak melelahkan mata saat belajar dalam waktu lama.

### 3. ⚡ Kuis Interaktif Mandiri (Self-Study Quiz)
- Kuis membaca (Hiragana) dan menulis (Kanji) langsung di browser.
- Dilengkapi pemeriksa otomatis (*instant feedback*), petunjuk furigana, dan penghitung skor evaluasi.

### 4. 🖨️ Siap Cetak A4 (Print-Ready) & Ekspor PDF
- Tampilan lembar kerja secara otomatis membersihkan navigasi dan tombol saat dicetak (`Ctrl + P`), menghasilkan dokumen A4 yang rapi dan elegan.

### 5. 📥 Unduhan Lengkap Microsoft Word (.docx)
- Tersedia berkas `.docx` per Bab (Bab 01 s.d. Bab 18) dan berkas **Master DOCX Lengkap** yang dapat langsung diedit pengajar atau dicetak di Word/WPS Office.

## 🚀 Cara Mempublikasikan ke GitHub (Deploy Jadi Aplikasi Web)

Proyek ini telah dikonfigurasi penuh dengan **GitHub Actions** dan **GitHub Pages** sehingga bisa langsung diakses online tanpa memerlukan hosting berbayar!

### Opsi A: Menggunakan GitHub Desktop (Paling Mudah)
1. Buka aplikasi **GitHub Desktop** di komputer Anda.
2. Klik menu **File** ➔ **Add Local Repository...**.
3. Pilih folder proyek ini: `c:\Users\Iqbal\Downloads\File MD A2.2`.
4. Klik tombol **Publish repository** di kanan atas.
5. Beri nama repositori (contoh: `irodori-kanji-studio`) lalu klik **Publish Repository**.
6. Buka halaman repositori Anda di browser GitHub:
   - Masuk ke tab **Settings** ➔ **Pages**.
   - Pada bagian **Build and deployment** ➔ **Source**, pilih **GitHub Actions** (atau **Deploy from a branch** ➔ pilih `main` dan folder `/(root)`).
7. Tunggu sekitar 1 menit. Situs web aplikasi Anda akan aktif di:
   ```text
   https://<username-github-anda>.github.io/<nama-repo>/
   ```

### Opsi B: Menggunakan Command Line (Git Terminal)
```bash
# 1. Masuk ke folder proyek
cd "c:\Users\Iqbal\Downloads\File MD A2.2"

# 2. Hubungkan ke repositori GitHub baru Anda
git remote add origin https://github.com/<username-anda>/<nama-repo>.git

# 3. Rename branch ke main & push
git branch -M main
git push -u origin main
```

## 💻 Menjalankan & Membangun Ulang Secara Lokal

Jika Anda ingin memodifikasi data atau menghasilkan ulang berkas DOCX/HTML:

```bash
# 1. Pasang dependensi
npm install

# 2. Bangun ulang aplikasi web index.html
node scripts/build_app.js

# 3. Bangun ulang berkas dokumen Word (.docx)
node scripts/generate_docx.js

# 4. Bangun ulang seluruh paket
npm run build
```
